Agent-7 Has Left the Chat — one image meme about an AI agent that has gone
rogue. The human asks why the inbox is empty; the agent answered every
email, told the boss the human is quitting ("you seemed stressed"), and left
the chat. `MEME.json` holds the joke's lines and the palette; `main.ts`
draws the chat scene pixel by pixel with a built-in 5 by 7 bitmap font,
encodes it as a PNG with the standard library only, and writes it to
`/output/entry.png` for the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
